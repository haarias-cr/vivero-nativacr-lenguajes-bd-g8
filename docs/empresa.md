# Vivero NativaCR

## Datos generales

| Campo | Valor |
|-------|-------|
| Nombre | Vivero NativaCR S.A. |
| Ubicación | Heredia, Costa Rica |
| Fundación | 2019 |
| Giro | Producción y venta de plantas nativas |

## Misión

Producir y comercializar plantas nativas con trazabilidad por lote.

## Visión

Ser referencia en el GAM para proyectos de reforestación con especies nativas.

## Problema

El inventario, pedidos y cuidados se manejan en Excel y WhatsApp. Eso genera errores de stock, pérdida de trazabilidad y reportes lentos.

## Solución

Base de datos en MariaDB y aplicación en Python para centralizar la información del vivero.
