# Código fuente

Programa en Python 3 con conexión a MariaDB.

| Archivo | Descripción |
|---------|-------------|
| `vivero_app.py` | Menú principal |
| `db.py` | Conexión a la base de datos |
| `test_conexion.py` | Verificación de conexión |
| `db_config.example.py` | Plantilla de configuración |

Copiar `db_config.example.py` como `db_config.py` antes de ejecutar.
